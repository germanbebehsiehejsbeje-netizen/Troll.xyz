TROLLHACK — Open Source Minecraft Client

    TROLLHACK — это инновационный Open Source чит-клиент для Minecraft 1.21.11, ориентированный на глубокую кастомизацию интерфейса и продвинутые методы обхода античитов.

🇷🇺 Русский (Russian)
🌟 Особенности

    Стиль Gamesense: Весь интерфейс выполнен в классическом стиле матового стекла с радужной акцентной полосой.

    Продвинутый TargetHUD: Отображение цели с рендерингом головы игрока справа, динамической полоской здоровья и кастомными шрифтами.

    PotionHUD с часами: Удобный список активных эффектов с иконками и индикатором времени в виде песочных часов.

    Обход Polar: Специальные алгоритмы для LongJump через TNT Boost и Blink (задержку пакетов) для обхода последних версий античита Polar.

    Open Source: Клиент полностью открыт для сообщества, код написан на Java с использованием Fabric API.

🛠 Установка (Разработка)

    Установите Java 21 (рекомендуется для стабильности на Arch Linux).

    Клонируйте репозиторий: git clone https://github.com/mzc/trollhack.git

    Импортируйте проект в IntelliJ IDEA.

    Выполните команду Gradle genSources, затем запустите клиент.

🇺🇸 English
🌟 Features

    Gamesense Visuals: A sleek glassmorphism-inspired UI featuring a signature rainbow accent line across all modules.

    Advanced TargetHUD: High-quality target display with right-aligned player head rendering, dynamic HP bars, and custom typography.

    Enhanced PotionHUD: Real-time effect tracking with integrated clock icons and precise duration displays.

    Polar Bypass: Specialized LongJump logic utilizing TNT Boost and packet-delay (Blink) mechanics designed to bypass Polar Anticheat.

    Open Source: Built with transparency in mind using Java and Fabric API for the 1.21.11 version of Minecraft.

🛠 Installation (Development)

    Ensure you have Java 21 installed (recommended for Arch Linux environments).

    Clone this repository: git clone https://github.com/mzc/trollhack.git

    Import the project into IntelliJ IDEA.

    Run the Gradle genSources task and launch the client.

💻 Tech Stack

    Language: Java

    Framework: Fabric

    Rendering: NanoVG

    Environment: Arch Linux + GNOME
