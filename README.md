## Содержание
TrollHack — это взломанный клиент для Minecraft, позволяющий разработчикам изменять и перекомпилировать исходный код игры. Основные возможности включают:
- Декомпиляция исходного кода Minecraft
- Написание и использование чит-функций
- Поддержка системы сборки Gradle
- Генерация рабочей модифицированной версии клиента
- Поддержка интеграции с Optifine
- Встроенные игровые оптимизации
